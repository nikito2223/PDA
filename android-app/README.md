# PDA Native Android

Нативная Android-версия в стиле исходного `HTML/CSS` интерфейса ПДА:

- левая панель меню как в веб-версии (Карта / Тайники / Дневник / Группировки);
- тёмная STALKER-палитра, нижняя статусная полоса и «терминальный» стиль;
- карта с режимами: **Здания / Ночная** (вместо спутника, чтобы не было артефактов);
- переключение локаций: **Дорогобуж / Чернобыль**;
- режимы карты: **Обзор / Создание меток**;
- создание, редактирование и удаление пользовательских меток;
- навигатор (маршрут до точки + расстояние).

## Данные
- `stashes` и `factions` загружаются с Supabase.
- пользовательские метки хранятся локально.

## Совместимость
- Android 8.0+ (`minSdk 26`).
