# PDA Native Android

Нативное Android-приложение в стиле PDA (без WebView), с ключевыми фишками из веб-версии:

- **Карта** с переключением **Обычная / Спутник**;
- переключение локаций **Дорогобуж / Чернобыль**;
- режимы карты: **Обзор / Создание меток**;
- создание меток по долгому нажатию, а также **редактирование/удаление** пользовательских меток;
- **Навигатор** (линия маршрута до выбранной метки + расстояние);
- разделы: **Тайники / Дневник / Группировки**.

## Откуда данные
Часть данных загружается с сервера (Supabase):
- `stashes` — для карты и списка тайников;
- `factions` — для списка группировок.

Пользовательские метки сохраняются локально на устройстве.

## Совместимость
- Android 8.0+ (`minSdk 26`).

## Автосборка APK
Workflow `.github/workflows/android-release-apk.yml` собирает debug APK и загружает его как artifact для ручного запуска workflow.
